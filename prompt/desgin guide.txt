# 🎨 Design Guide for Yarden Gabbay’s Website

This guide outlines the visual identity, UX tone, layout rules, and styling decisions for the website. The design should reflect **warmth, professionalism, clarity, and emotional depth**, supporting the tone of a clinical psychologist working with trauma, resilience, and emotional well-being.

---

## 🌈 Color Palette

### Primary Background
- `#eeedeb` → Use as the **default background** for all pages. Clean, warm, and soft.

### Primary Accent & Footer
- `#a06a4d` → Rich brown tone for the **footer**, primary **call-to-action buttons**, and **section dividers**.

### Secondary Accents
Use sparingly for depth, contrast, or highlights:

| Purpose                    | Color Code  | Usage                                           |
|----------------------------|-------------|--------------------------------------------------|
| Article Tags               | `#bf977d`   | Neutral pink-tan, soft category tags             |
| Hover & Link Effects       | `#9f5e36`   | Warm rust-orange for hover/focus states          |
| Blockquotes / Highlights   | `#cfc0b7`   | Light creamy grey to separate key content        |
| Sidebar / Filter UI        | `#c7aea2`   | Pale muted pink for background accents           |
| Secondary Text / Notes     | `#b4a59d`   | Subheadings, small notes                         |
| Card Backgrounds           | `#d9cac5`   | Gentle pinkish-gray for content blocks           |
| Accent Buttons (alt)       | `#b97c44`   | For secondary buttons like “Read More”           |
| Form Borders / Lines       | `#ccc7c4`   | Subtle outlines, input borders                   |

Use generous white/neutral space between colored elements. Avoid overwhelming the user with too many accent colors at once.

## 🖋 Typography

### Hebrew Fonts
- **Primary**: `Assistant`
- **Alternate**: `Noto Sans Hebrew`

### English Fonts
- **Primary**: `Lora` (serif, for elegance)
- **Alternate**: `Open Sans` (clean sans-serif for UI text)

### Typography Guidelines
- Use **large headings** with generous spacing
- Break content into **short blocks of text**
- Avoid justified text (left-align for natural flow)
- Maintain **consistent font sizes** across languages

| Text Type       | Font         | Style/Size Example         |
|------------------|--------------|-----------------------------|
| Main Headings    | Lora / Assistant | Bold, ~36–48px              |
| Subheadings      | Open Sans / Assistant | Semi-bold, ~20–24px    |
| Body Text        | Open Sans / Assistant | Regular, ~16–18px        |
| Quotes/Highlights| Lora Italic | ~18px, colored bg if needed |

---

## 🧭 UX & Layout Guidelines

### General Feel
- Minimalist, clean, and **emotionally calm**
- Support **trust** and **professionalism** without coldness
- Use **soft spacing**, round corners, and large padding

### Navigation
- Fixed top nav with subtle scroll background (transparent → `#eeedeb`)
- Mobile menu should slide in smoothly
- Use sticky sidebar or filter menus for longer sections (like Publications)

### Content Blocks
- Each section should breathe — use **clear vertical spacing**
- Divide longer sections with neutral backgrounds (`#cfc0b7`, `#ccc7c4`)
- Alternate light content blocks with white background for rhythm

### Interactions & Feedback
- **Hover effects**: Buttons and links change to `#9f5e36`, underline or fade
- **Forms**: Minimal style with `#ccc7c4` borders, focus state with `#a06a4d`
- **“Read More” buttons**: Slight raise or shadow on hover
- **Tags**: Rounded pills using `#bf977d` or `#c7aea2`

---

## ✨ Animations & Motion

Use **subtle, elegant animations** that support clarity without distraction:

- **Text Fade-In on Load** (`opacity 0 → 1`, delay staggered per section)
- **Slide-In from Bottom or Side on Scroll** (used on article cards, FAQ items)
- **Hover States**: Soft color shift, slight scale (max 1.03), underline on links

**Avoid**:
- Fast or flashy transitions
- Parallax, bounce, or sudden scaling

Images — Global Rules (apply to all pages)

Files live at /images/ 
Use these exact filenames (lowercase, no spaces):
habait.jpg, therapy.jpg, red-door.jpg, rainbow.jpg, ipad.jpg, books-in-the-back.jpg, writing.jpg, coffee.jpg, desk-ipad.jpg, couch.jpg

If an image is missing, render a visible placeholder: a light box with the text IMAGE MISSING: <filename> (do not hide).

Markup: wrap each image in <figure> with <img> + <figcaption> (optional).

Accessibility: meaningful alt text; loading="lazy".

Sizing: responsive, 16:9 for heroes, 4:3 for content images.
Use object-fit: cover; object-position: center;

Styling: rounded corners, soft shadow, subtle hover zoom (respect prefers-reduced-motion).

RTL/LTR: images align center on mobile; on desktop, follow layout rules below and auto-flip margins for RTL.

## 🧩 Final Notes

- All elements should **feel breathable and slow-paced** — space is part of the design.
- Use a **warm but professional tone** throughout: never cold, never overly casual.
- If unsure, **lean into simplicity** — fewer styles, more clarity.
