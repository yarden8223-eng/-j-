## 🌍 Bilingual & Language Toggle Requirements

- **Default Language**: Hebrew (`lang="he"`) with `dir="rtl"` applied to the `<html>` element on all pages by default.
- **Secondary Language**: English (`lang="en"`) with `dir="ltr"`.
- **Language Toggle**:
  - A persistent toggle in the header on **every page** that allows switching between Hebrew and English versions.
  - Toggle must be accessible via keyboard (`Tab` navigation) and screen reader-friendly (`aria-label="Change language to English"` / `"Change language to Hebrew"` depending on current language).
  - The current language should be visually indicated (highlight, underline, or icon).
- **Consistent Layout Direction**:
  - When Hebrew is active: all text, navigation, and layout flow should be RTL.
  - When English is active: all text, navigation, and layout flow should be LTR.
- **Text Content**:
  - Both Hebrew and English content for each page should be stored and linked so that toggling preserves the current page (e.g., Hebrew About → English About, not defaulting back to Home).
  - All pages must load the correct language version based on the toggle state.
- **HTML Markup**:
  - Hebrew page root:  
    ```html
    <html lang="he" dir="rtl">
    ```
  - English page root:  
    ```html
    <html lang="en" dir="ltr">
    ```
- **Mixed Language Segments**:
  - If a section or phrase uses the other language (e.g., English phrase in a Hebrew page), wrap it in a `span` with the correct `lang` attribute:  
    ```html
    <span lang="en">choose your mind</span>
    ```
- **Navigation Bar**:
  - Hebrew default order: RTL with "בית" as the rightmost link.
  - English order: LTR with "Home" as the leftmost link.
- **Testing**:
  - Verify the toggle updates both `lang` and `dir` attributes on every page.
  - Ensure CSS respects `[dir="rtl"]` and `[dir="ltr"]` for layout adjustments.
